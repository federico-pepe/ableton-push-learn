Max for Live Device

Ableton Push and Move Visualizer

The Push and Move Visualizer is now available as a Max for Live device.
You can load it onto a MIDI track and use the visualizer directly inside your Ableton Live set. The features are identical to those of the web app, with a few added benefits:

  • Easier setup and routing
  • No need for an internet connection or web browser
  • Automatically follows Live's theme color
  • Automatically follows your set's key and scale
  • Control the device with Push and Move's knobs

System requirements

Ableton Live 12
Max for Live

Optional

Ableton Push 1, 2, 3 or 3 Standalone
Ableton Move
