Max for Live Device

Ableton Push and Move Visualizer

The Push and Move Visualizer is now available in a practical Max for Live format.
Add this MIDI effect on a track and use the visualizer inside your Ableton Live set. Compared to the web-app version there are some benefits:

  • Easier routing
  • Follow Live's theme color automatically
  • Follow Live's Root/Key automatically
  • Control the device from Push and Move

System requirements

Ableton Live 12
Max for Live

Optional

Ableton Push 1, 2, 3 or 3 Standalone
Ableton Move
